Built-in Security Safeguards

Werkzeug Salted Password Hashing

Passwords are never stored in plain text. Stored as scrypt/pbkdf2 salted hashes.

Ownership Authorization

Every file action verifies file.user_id == current_user.id on the server.

Path Traversal Defense

Files are stored by UUID inside user directories outside the public web root.

CSRF Token Protection

All forms and file actions require valid CSRF verification tokens.
